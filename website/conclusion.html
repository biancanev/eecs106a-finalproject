Conclusion

Overall, our project worked successfully to our expectations, and in some cases even exceeded expectations. The integration of sophisticated algorithms enabled robust autonomous navigation and interception.

Project Success

We successfully implemented an autonomous interception system that integrates multiple advanced algorithms:

  • Multi-Modal Perception: 6-layer HSV filtering, LIDAR-based mapping, automatic frame calibration
  • Advanced State Estimation: 100 Hz EKF for robot pose, UKF for target tracking, state propagation during occlusions
  • Optimal Control: MPC with obstacle avoidance, waypoint generation, terminal guidance
  • Robust Integration: Real-time sensor fusion, coordinate frame transformations, confidence-based data association

The system successfully navigates cluttered environments, avoids obstacles, and intercepts moving targets. In several test runs, the MPC found more optimal paths than anticipated, demonstrating the effectiveness of the optimization-based approach.

Technical Challenges & Solutions

1. LIDAR Frame Calibration

Challenge: LIDAR mounting orientation was unknown, making obstacle positions incorrect without calibration.

Solution: Developed automatic frame offset detection by testing candidate orientations [0°, 90°, 180°, 270°] and selecting the one with highest geometric consistency (obstacle matching) with the occupancy grid. This eliminated manual calibration errors and worked across different hardware setups.

2. Camera Detection Robustness

Challenge: Simple HSV filtering produced excessive false positives (60% precision), making obstacle detection unreliable.

Solution: Designed a 6-layer progressive filtering system: (1) HSV color segmentation, (2) morphological operations, (3) geometric heuristics (aspect ratio, area), (4) triangular shape analysis (polygonal approximation, width ratio), (5) solidity and color validation, (6) position and depth checks. This improved precision to ~95% while maintaining ~90% recall.

3. MPC Cost Function Tuning

Challenge: Initial MPC preferred curved paths even when straight paths were optimal, and didn't strongly avoid obstacles.

Solution: Iteratively tuned cost weights: increased heading alignment (Qθ = 25.0), angular velocity penalty (Rw = 0.15), and obstacle cost (Q_obs = 900.0). Added terminal cost multipliers (10×) for strong goal constraints. This resulted in smoother, straighter trajectories with effective obstacle avoidance.

4. Target Depth Estimation

Challenge: Camera-based depth estimation for target cone was consistently underestimated (appeared 1.4 m when actually 2.5-3 m away).

Solution: Discovered target cone is elevated ~10 cm above ground. Adjusted depth estimation by using 7× larger area constant (0.146 m² vs 0.021 m² for yellow cones) to account for the larger apparent size. Added explicit elevation handling in coordinate transforms (z = 0.1 m).

5. State Estimation During Occlusions

Challenge: Target frequently occluded by obstacles, causing tracking to fail and MPC to lose target.

Solution: Implemented state propagation using constant velocity model when detections are unavailable. Confidence decays exponentially (0.9 × exp(-0.5 × dt)) with minimum floor (0.2). System maintains target estimate for 2-3 seconds during occlusions, enabling continuous tracking.

6. Real-Time Performance

Challenge: Multiple algorithms (EKF, UKF, MPC, perception) need to run in real-time without lag.

Solution: Chose computationally efficient algorithms: EKF over MCL (deterministic, faster), fast local grid (5-10 Hz) over full SLAM updates, CVXPY with efficient solvers (ECOS, OSQP). Achieved 10 Hz MPC control with <200 ms end-to-end latency.

7. Sensor Fusion & Data Association

Challenge: Multiple sensor sources (LIDAR, camera, grid) provide redundant but noisy obstacle detections. Need to fuse them intelligently.

Solution: Confidence-based fusion with source prioritization: grid (95%) > LIDAR (90%) > scan-matched (88%) > camera (70-80%). Camera detections refine LIDAR positions at close range (60% LIDAR distance + 40% camera angle). Duplicate merging within 20 cm keeps highest-confidence or largest-radius obstacle.

Algorithmic Contributions

Novel Aspects

  • 6-Layer HSV Filtering: Progressive filtering system that dramatically improves precision while maintaining recall
  • Automatic LIDAR Calibration: Multi-hypothesis testing approach that eliminates manual setup
  • State Propagation with Confidence Decay: Maintains target tracking during occlusions with appropriate uncertainty handling
  • Multi-Modal Sensor Fusion: Confidence-based weighting that adapts to sensor reliability at different ranges
  • Adaptive Velocity Scaling: Dynamic speed adjustment based on obstacle proximity for smooth, safe navigation

Integration Complexity

The system integrates 9+ ROS2 nodes with complex data flows:

  • Coordinate frame transformations (base_link, map, camera, LIDAR)
  • Multi-rate sensor processing (30 Hz camera, 10 Hz LIDAR, 100 Hz IMU)
  • State synchronization across estimation filters
  • Real-time obstacle fusion from multiple sources
  • MPC optimization with dynamic obstacle constraints

Future Work

With more time, we would focus on several improvements:

Robustness Improvements

  • Trajectory Smoothness: Current implementation can be jerky during waypoint transitions. Future work would add trajectory smoothing (e.g., spline interpolation) or increase MPC horizon for longer-term planning.
  • General Obstacle Types: Current system optimized for cone-shaped obstacles. Extending to arbitrary obstacle shapes (walls, irregular objects) would improve generality.
  • Dynamic Obstacle Handling: Current system assumes static obstacles. Adding velocity estimation and prediction for moving obstacles would enable navigation in dynamic environments.

Algorithmic Improvements

  • L₁ Adaptive Control: As an alternative to MPC, L₁ adaptive control could provide faster computation and better robustness to model uncertainties. This would be worth exploring for comparison.
  • Learning-Based Perception: Deep learning models (e.g., YOLO) could replace heuristic filtering for more robust detection across lighting conditions. We already have YOLO integration as optional fallback.
  • Multi-Hypothesis Tracking: For highly uncertain environments, maintaining multiple target hypotheses (particle filter for target) could improve robustness.
  • Optimal Time-to-Go: Current MPC minimizes distance to goal. Minimizing time-to-intercept (with velocity constraints) could provide faster interception.

Performance Optimization

  • Parallel Processing: Distributing perception, estimation, and control across multiple CPU cores could reduce latency
  • GPU Acceleration: Camera processing and MPC solving could benefit from GPU acceleration for faster performance
  • Code Optimization: Further refactoring and optimization of the extracted modules (obstacle extractor, safety utils) could improve real-time performance

Reflections

This project demonstrated the complexity of real-world autonomous systems. Integrating perception, estimation, and control required careful attention to:

  • Sensor Calibration: Automatic calibration was essential—manual setup was too error-prone
  • Robustness: Multiple sensor modalities and state propagation were necessary for reliable operation
  • Real-Time Constraints: Algorithm choices were driven by computational efficiency, not just accuracy
  • Integration Complexity: Coordinate frames, timing, and data association were as challenging as the core algorithms
  • Iterative Development: Extensive tuning and testing were required to achieve desired performance

The final system successfully demonstrates autonomous interception with obstacle avoidance, showcasing the integration of advanced algorithms from perception (6-layer filtering, LIDAR calibration) to control (MPC optimization, terminal guidance). The project highlights both the challenges and successes of building real-world robotics systems.
