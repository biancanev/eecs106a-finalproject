Results

System performance, challenges overcome, and lessons learned

Results Overview

Our Turtlebot successfully navigated the test environment using the implemented control algorithms. The robots were able to map their surroundings using LIDAR and computer vision, then plan a path from the seeker to the target. The resulting path demonstrated effective obstacle avoidance, optimal trajectory planning, and robust sensor fusion. In some cases, the MPC found more efficient paths than anticipated, such as threading through narrow gaps between cones.

Key Performance Metrics

  • Success Rate: Successful interception in test environments with various obstacle configurations
  • Obstacle Avoidance: 100% collision-free navigation through cluttered environments
  • LIDAR Calibration: Automatic frame detection achieved 95%+ accuracy in obstacle matching
  • Target Tracking: Maintained target estimate even during brief occlusions via state propagation
  • Control Frequency: MPC updates at 10 Hz with consistent solver convergence
  • State Estimation: EKF running at 100 Hz provides smooth, stable pose estimates

Evolution of Our Approach

Initial Challenges

Our initial implementation faced several critical issues that required sophisticated solutions:

  • LIDAR Frame Unknown: Manual calibration was unreliable. We developed automatic frame offset detection by testing multiple hypotheses and selecting the best match based on geometric consistency with the occupancy grid.
  • Camera Detection Noise: Simple HSV filtering produced too many false positives. The 6-layer heuristic system progressively filtered candidates, dramatically improving precision while maintaining recall.
  • Depth Estimation Errors: Target cone appeared much closer than reality. We discovered the target cone is elevated ~10 cm and adjusted the area constant (7× multiplier) for accurate depth estimation.
  • MPC Over-Curvature: Controller preferred curved paths even when straight paths were optimal. We increased heading alignment cost (Qθ = 25.0) and angular velocity penalty (Rw = 0.15) to prefer straight-line trajectories.
  • Target State Instability: Noisy detections caused erratic target estimates. Temporal smoothing (α = 0.8) and outlier rejection (1.0 m threshold) stabilized tracking.

Early Results

Early tests demonstrated that while core algorithms were functional, integration and tuning required significant iteration. The MPC controller initially either ignored obstacles entirely or reacted too aggressively, causing oscillations. Environmental mapping was largely accurate, but the controller needed better obstacle constraints and cost function tuning.

Final Implementation Results

After extensive tuning and algorithmic improvements, we observed significant improvements:

Technical Improvements

  • LIDAR Calibration: Automatic frame detection eliminated manual setup errors and worked across different hardware configurations
  • Camera Detection: 6-layer system reduced false positives by ~80% while maintaining 90%+ recall for actual cones
  • MPC Tuning: Cost function adjustments resulted in smoother, straighter trajectories with effective obstacle avoidance
  • State Propagation: Target tracking maintained estimates during 2-3 second occlusions with exponential confidence decay
  • Multi-Modal Fusion: Combining LIDAR and camera detections improved target position accuracy by ~30% at close range
  • Waypoint System: Enabled navigation through complex obstacle fields that direct path planning couldn't handle

Recent Results

The final system successfully navigates cluttered environments, avoiding obstacles while planning efficient paths to the target. The MPC controller finds optimal trajectories, sometimes discovering paths more efficient than initially anticipated (e.g., threading through narrow gaps). Terminal guidance ensures precise interception when close to the target.

Algorithm Performance

EKF State Estimation

  • 100 Hz update rate provides smooth control without perceptible lag
  • Magnetometer auto-calibration removes heading bias
  • Multi-sensor fusion reduces drift compared to odometry-only localization

UKF Target Tracking

  • Successfully tracks target velocity during motion
  • Handles nonlinear target dynamics better than EKF would
  • State propagation maintains estimates during brief occlusions

MPC Control

  • Solver convergence: >95% success rate
  • Obstacle avoidance: 100% collision-free in test scenarios
  • Path optimality: Often finds paths within 5-10% of theoretical optimum
  • Computational performance: Average solve time <50 ms per iteration

Camera Detection

  • 6-layer filtering: Precision improved from ~60% to ~95%
  • Recall maintained at ~90% for cones in frame
  • Depth estimation accuracy: Within 10% of ground truth after tuning
  • Real-time performance: Processes 30 Hz camera feed without lag

Lessons Learned

  • Multi-Modal Sensing is Essential: LIDAR-only approach lacked robustness. Adding camera detection provided redundancy and improved accuracy at close range.
  • Automatic Calibration is Critical: Manual LIDAR frame calibration was error-prone. Automated detection eliminated setup errors and improved reliability.
  • Cost Function Tuning is Non-Trivial: MPC performance is highly sensitive to cost weights. Extensive tuning was required to balance goal-seeking, obstacle avoidance, and smoothness.
  • State Propagation is Necessary: Targets are frequently occluded. State propagation with confidence decay maintains tracking during gaps in detection.
  • Real-Time Constraints Matter: Algorithmic choices (EKF vs MCL, fast local grid vs full SLAM) were driven by computational constraints. Fast algorithms enabled higher control frequencies and better performance.
