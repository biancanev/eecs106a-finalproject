Turtlebot Interceptor

Autonomous Interception System with Multi-Modal Perception, Optimal Control, and Robust State Estimation

Project Overview

The goal of our project was to deploy two Turtlebots in an unknown environment with obstacles obstructing the path between them. Our task was to design and implement a system in which one Turtlebot, designated as the seeker, intercepts a target Turtlebot—potentially in motion—in optimal time by mapping its surroundings and determining the most efficient path to the target.

This project required the integration of multiple sophisticated algorithms:

  • Multi-Modal Perception: 6-layer HSV filtering system for camera-based cone detection, LIDAR-based occupancy mapping, and automatic LIDAR frame calibration
  • Advanced State Estimation: Extended Kalman Filter (EKF) running at 100 Hz for robot pose, Unscented Kalman Filter (UKF) for target velocity tracking, with state propagation during occlusions
  • Optimal Control: Model Predictive Control (MPC) with receding-horizon optimization, obstacle avoidance constraints, and adaptive velocity scaling
  • Geometric Algorithms: Kabsch algorithm for LIDAR-based target localization, RANSAC for robust transform estimation
  • Real-Time Processing: Fast local occupancy grid (5-10 Hz) for immediate obstacle awareness, complementing Cartographer's global SLAM

Key Technical Achievements

Perception

  • 6-layer heuristic system for robust cone detection in varying lighting
  • Automatic LIDAR frame calibration (0°, 90°, 180°, 270° detection)
  • Multi-modal sensor fusion with confidence-based weighting
  • Fast local grid at 5-10 Hz for real-time obstacle awareness

State Estimation

  • 100 Hz EKF fusing IMU, magnetometer, and odometry
  • UKF for nonlinear target velocity tracking
  • State propagation during sensor occlusions
  • Temporal smoothing and outlier rejection

Control

  • MPC with 15-step horizon and obstacle constraints
  • Adaptive velocity scaling based on obstacle proximity
  • Waypoint generation for complex obstacle navigation
  • Terminal guidance for precise final approach

Inspiration

Our work was inspired by ongoing research in interception systems, as well as missile interception technologies in which one missile autonomously intercepts another. The challenges observed in these systems reflect many of the difficulties we encountered in our project, including accurately mapping noisy environments, fusing multiple sensor modalities, handling sensor occlusions, and successfully planning an optimal trajectory in real-time.

Like production autonomous systems (Waymo's LIDAR+camera fusion, Tesla's camera-based perception), our system leverages multi-modal sensing to achieve robustness that single-sensor systems cannot provide. The integration of geometric algorithms (Kabsch), optimal control (MPC), and advanced filtering (EKF, UKF) demonstrates the complexity required for real-world autonomous navigation.
