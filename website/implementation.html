Implementation Details

Obstacle Detection

Obstacles are detected using both lidar and camera sensors. Camera detects obstacles(Yellow Cones) through color and shape filtering. LIDAR filters raw scans which are then used to build a fast local robot-centric occupancy grid. These cone positions and the occupancy grid are used to plan paths around obstacles in our MPC node.

  • Input: raw lidar / camera / fused sensor data
  • Algorithm: Color segmentation, shape filtering, Ray-casting occupancy update
  • Output: bounding boxes, occupancy grids, confidence scores

Target Detection

Detail how targets are detected and classified, and how detections are tracked over time.

Method 1 — LIDAR and Procrutes Algorithm

Use image processing and rule-based heuristics for detection. This method is lightweight and interpretable.

  • Approach: color/shape filtering, edge detection, morphological ops
  • Pros: fast, explainable, easy to tune
  • Cons: brittle to lighting and appearance changes

Method 2 — USB Logitech Camera

Use a trained detector (e.g., CNN) for more robust detection and classification under varied conditions.

  • Approach: object detector (YOLO/SSD/Faster-RCNN) or classification + bbox regression
  • Pros: robust to variation, higher recall/precision when trained well
  • Cons: needs labeled data and more compute
  • Association: data association / tracking filters
  • Metrics: precision, recall, latency
