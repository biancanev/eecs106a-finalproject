The seeker turtlebot follows the MPC-calculated optimal trajectory. \\
\hline
\hline
\multicolumn{3}{|c|}{\textcolor{slidegreen}{\textbf{Activities}}} \\
\hline
\vspace{0.1cm}
→ Integrate Cartographer SLAM for global mapping

→ Develop Fast Local Grid for real-time obstacle awareness (5-10 Hz)

→ Integrate 6-layer HSV heuristic system on USB camera to detect cones

→ Implement LIDAR-based target localization using map origins and Kabsch algorithm

→ Handle elevated target cone (~10 cm above ground) in depth estimation & → State estimation of seeker using Extended Kalman Filter (EKF) fusing IMU, magnetometer, and encoders (100 Hz)

→ State estimation of target using multi-sensor fusion (LIDAR map alignment + camera detections + UKF for velocity tracking)

→ Plan optimal trajectories using Model Predictive Control (MPC) with obstacle constraints & → MPC directly outputs velocity commands (\texttt{/cmd\_vel}) to robot base

→ Design simple target trajectories for testing

→ Implement terminal guidance for final approach \\

→ Robust LIDAR-based target pose estimation with confidence scoring & → High-rate EKF pose estimation (100 Hz) for smooth control

→ Accurate target state estimation with state propagation during occlusion

→ Efficient, autonomous navigation through obstacles with MPC

→ States and confidences visualized in RViz & → Smooth trajectory following via MPC

→ Terminal guidance and final approach behaviors
